# Security and privacy control matrix

This inventory is a release control, not an API guide. `npm run security:matrix`
compares every marker below with every Nest controller route and Prisma model so
new surfaces cannot land without an explicit control decision.

Shared controls:

- **Session** means `SessionAuthGuard` authenticates an opaque, hashed,
  unexpired session and supplies the owner ID; request bodies never supply
  ownership authority.
- **Origin** means `CsrfOriginGuard` requires an allowlisted browser origin for
  cookie-authenticated mutations.
- **IP** means the global bounded in-memory IP limiter. **Auth IP** is the
  stricter authentication-attempt limiter. **AI user** is the per-user request
  limiter and concurrency gate. These controls assume one API replica.
- Helmet headers, strict CORS, a 64 KiB default JSON/form limit, stable
  exceptions, and body/token-free application logging policy apply globally.
- `Zod` means unknown fields are rejected by a strict runtime contract unless a
  route has no request body or parameters.

## Persisted-table controls

| Prisma model                                              | Ownership authority                         | Sensitive content and access                 | Retention                                          | Account deletion                    |
| --------------------------------------------------------- | ------------------------------------------- | -------------------------------------------- | -------------------------------------------------- | ----------------------------------- |
| <!-- table: User --> `User`                               | Primary account ID                          | Email/profile only via authenticated self    | Until explicit deletion                            | Root row hard-deleted; no tombstone |
| <!-- table: UserPreferences --> `UserPreferences`         | `userId` PK                                 | Owner-only settings                          | Until account deletion                             | Database cascade                    |

## Verification ownership

- `apps/api/test/security-privacy.integration-spec.ts` owns headers, body limit,
  auth/IP rate limits, reauthentication, deletion cascade, retention, and
  sanitized-error coverage.
- Existing feature integration suites own route-level authentication,
  cross-user isolation, Origin enforcement, pagination, and transactional rules.
- `npm run security:secrets` rejects tracked credential files and known provider
  credential formats without printing matched secret values.
